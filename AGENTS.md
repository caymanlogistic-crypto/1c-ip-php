# Работа в текущем локальном каталоге

Этот файл действует для единственного канонического каталога, в корне которого он расположен.
Прочитай START-HERE.md и CURRENT-SPEC.md, затем код нужной функции.
Действующие факты сборки берутся из START-HERE.md; старые worktree и handoff не являются активным приложением.

## Выполнение поручений

Выполняй порученные владельцем обратимые локальные изменения самостоятельно до проверяемого результата.
Конкретное поручение владельца разрешает соответствующую узкую правку; не спрашивай повторное общее разрешение.
Не превращай небольшой отступ, текст или форму в задачу root + два исполнителя + reviewer.
Новый агент работает здесь; не создавай worktree, реплики приложения, тестовые framework или второй ledger без конкретной необходимости и поручения.
Сначала проверь git status и сохрани чужие изменения.
Правь маленькими смысловыми группами; не смешивай незапрошенную переработку интерфейса или архитектуры.
Закрепляй завершённую группу отдельным Git-коммитом, включай только свои файлы.
Обновляй текущие три документа только при изменении их фактов, без дублирования истории по всем файлам.

## Проверка изменения

Для PHP выполни php -l затронутых файлов, проверь diff и один сценарий изменённого поведения.
Если менялись права, проверь разрешённую роль и отказ запрещённой роли.
Миграцию применяй только на отдельной разрешённой копии данных.
Повторяй конкретную упавшую проверку; широкий набор нужен только при изменении общего контракта или явном поручении.
Не возобновляй широкую приёмку и не создавай новые тестовые обвязки без поручения.
Для узкой локальной правки достаточно необходимого синтаксиса и одной адресной проверки.
Визуальную правку сверяй в браузере, включая доступность нижних действий в коротком окне.

## Данные и границы

Не удаляй бизнес-данные, не очищай базу и не пересоздавай схему без явного задания.
Не удаляй реальные и неизвестные данные; очищай однозначные QA-записи на копии только по явному заданию.
Не переносить в Git пароли, cookies, токены, ключи или приватные payload; использовать существующие private carriers.
Обычный запуск не означает Setup, импорт, миграцию или restore.
Не перезапускай чужое приложение и не меняй глобальную конфигурацию компьютера.
Сервер, SSH, production и внешние подключения не входят в текущее локальное поручение.
Не повторяй операцию с неизвестным эффектом до чтения её фактического результата.

## Интерфейс и результат

Используй текущие согласованные правила, существующие компоненты UI, палитру и роли.
Не добавляй произвольный CSS и не обходи FROZEN/guard для упрощения правки.
Отдельную UI-ветку не сливать автоматически до явного owner«всё»; точный порученный owner-delta имеет приоритет.
Нужное защищённое изменение ограничь порученным объёмом и штатным механизмом защиты.
Различай требование, выполненный код, установленную версию и наблюдавшийся результат.
Не называй source-only проверку фактическим UI PASS; полная функциональная приёмка не завершена, владелец проверяет текущую версию.
В результате сообщи, что изменено, commit, адресную проверку и конкретный остаток.
